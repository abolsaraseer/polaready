Color

Two brand tones, plus three neutrals

Navy and Cream aren't approximations — they're the exact hex values pulled straight from the logo file. Cream reads warm on its own, which breaks the "no warm colors" rule on purpose: it's the real, approved brand tone, not a decorative accent. Glacier still carries every link, highlight and call-to-action; Snowbank and Ash Line round the system out.

Type

Three faces, three jobs

Fugaz One only ships one weight, so it never carries hierarchy alone — Nunito Sans does every job Fugaz One can't: subheads, body copy, buttons. IBM Plex Mono handles labels, tags and anything that should read as data.

Display — Fugaz One, weight 400 only

Made for the whiteout

Headlines, the wordmark, hero lines. Never bolded — browsers fake-bold a single-weight face, so size and color carry emphasis instead of weight.

Body / UI — Nunito Sans, weights 200–1000

Before it ever meant an instant photo, Polaroid meant: I can see clearly in a place too bright to look at. Nunito Sans carries every paragraph, button and caption in the system — its rounded terminals echo Fugaz One without competing with it.

The mark

Two grounds

The mark is the paw print straight from the logo file — one heel pad, three toe pads. With no accent color in the system, it only needs to prove itself on light and dark: Cream for everyday use, Navy for booth signage, merch and anywhere the brand needs to hold a dark room.
